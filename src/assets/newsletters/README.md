# Newsletter designs

Drop skill-showcase designs here (PNG, JPG, or WebP), then import them in `src/App.jsx` and set `image` on the matching skill card:

- Marketing Newsletters
- Purchase-Behavior Segmentation
- Abandoned Cart Automation
- Platform Setup & Delivery

Example:

```js
import marketingSample from './assets/newsletters/marketing-sample.jpg'

// in newsletters array:
image: marketingSample,
```
